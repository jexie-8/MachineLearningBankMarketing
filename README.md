# Bank Marketing ML Coursework

This project predicts whether a customer will subscribe to a term deposit before a marketing call.

## Dataset

- Source: UCI Machine Learning Repository - Bank Marketing
- URL: https://archive.ics.uci.edu/dataset/222/bank+marketing
- DOI: https://doi.org/10.24432/C5K306
- Working file: `data/bank-full.csv`

The personalized dataset is a stratified 80% subsample generated with TKH Student ID `202300404` as the random seed. It contains 36,168 rows.

## Environment

Use Python 3 and install the pinned packages in `requirements.txt`. The local `.venv` directory is intentionally excluded from version control.
